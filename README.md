# Retinal Image AI Research

Research repository for applying artificial intelligence methods to the processing and analysis of retinal medical images.

## Research

This repository is part of the master's thesis:

**"Methods of Artificial Intelligence in Medical Image Processing"**

**Research focus:** application of artificial intelligence and deep learning methods to the processing and analysis of retinal fundus images.

The repository contains the research code, experiments, and results developed during the master's thesis.

**Related publication:**
The scientific publication related to this research will be added after its publication and assignment of a DOI.

## Installation

Clone the repository:

```bash
git clone https://github.com/Ilan-Ysm/retinal-image-ai-research.git
cd retinal-image-ai-research
```

Install the required Python dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Example of running the research pipeline:

```bash
python scripts/run_experiment.py
```

The exact experimental scripts and parameters will be added as the research progresses.

## Data

The project uses retinal medical images for research and experimental evaluation.

Due to dataset size and licensing restrictions, the original medical datasets are not stored directly in this repository.

The required datasets should be downloaded from their official sources and prepared according to the instructions provided with the corresponding dataset.

Large datasets should not be uploaded to GitHub. Dataset sources and access instructions will be documented as the research develops.
